# FP学習データ

`fp.html`（FP技能検定の学習ページ）が読み込む問題データ。

## ファイル構成

```
fp-data/
├ tax.json          ← アプリが読む生成物。直接編集しない
├ README.md
└ src/              ← 編集するのはこちら
   ├ build.py           結合＋整合性チェック＋出力
   ├ tax_cards_a.json   論点カード U1〜U4
   ├ tax_cards_b.json   論点カード U5〜U13
   ├ tax_q3_a.json      3級問題 U1〜U4
   ├ tax_q3_b.json      3級問題 U5〜U10
   ├ tax_q2_a.json      2級問題 U1〜U10
   └ tax_q2_b.json      2級問題 U11〜U13（法人税・消費税・決算書）
```

## 更新手順

1. `src/` の分割JSONを編集する
2. ビルドして検査を通す

```bash
bash ~/.claude/scripts/run_py.sh fp-data/src/build.py
```

3. エラーが1件でも出たら `tax.json` は出力されない。直してから再実行
4. `tax.json` と `src/` の両方をコミットする

`tax.json` を直接編集しないこと。下記の検査を素通りしてしまう。

## build.py が検査すること

| 検査 | 内容 |
|---|---|
| ID重複 | カード・問題のIDが一意か |
| 参照整合 | 問題の `card` / `unit`、カードの `prereq` が実在するか |
| 正解index | `a` が選択肢の範囲内か（○×は0/1） |
| 選択肢 | 重複した選択肢がないか、3級は3択・2級は4択か（警告） |
| 解説 | `exp` が空でないか |
| 表 | `head` と各 `rows` の列数が一致するか |
| 文字混入 | キリル文字など想定外の文字が入っていないか |
| カバレッジ | 全単元にカードと問題が存在するか |

## データ形式

### 論点カード

```json
{
  "id": "tax-c01", "unit": "U1", "level": 3,
  "title": "見出し", "summary": "1行要約",
  "prereq": ["tax-c03"],
  "body": [
    {"t": "h",     "v": "小見出し"},
    {"t": "p",     "v": "本文。**強調**が使える"},
    {"t": "ul",    "v": ["項目1", "項目2"]},
    {"t": "table", "head": ["列1","列2"], "rows": [["a","b"]]},
    {"t": "note",  "v": "黄色の補足ボックス"}
  ],
  "pitfalls": ["ひっかけポイント"]
}
```

`level` は「その級から必要になる論点か」。3級モードでは `level: 2` の単元は非表示になる。
`prereq` に未読のカードがあると、詳細画面に「先に○○を読むと理解が速い」と出る（読まずに進むのは自由）。

### 問題

```json
{"id":"tax-q3-001","unit":"U1","card":"tax-c01","level":3,
 "type":"ox","q":"問題文","a":1,"exp":"解説"}

{"id":"tax-q2-001","unit":"U1","card":"tax-c01","level":2,
 "type":"mc","q":"問題文","c":["選択肢1","選択肢2","選択肢3","選択肢4"],"a":0,"exp":"解説"}
```

`type: "ox"` は `a` が `0`＝○（正しい）、`1`＝×（誤り）。`c` は不要。

## 他の分野を追加するとき

1. `src/` に `<area>_cards_*.json` / `<area>_q3_*.json` / `<area>_q2_*.json` を作る
2. `build.py` をコピーして `UNITS` と読み込むファイル名、`area` / `areaName` / `icon` を差し替える
3. `fp.html` の `AREAS` 配列で該当分野を `ready: true` にする

## コンテンツ方針

- **公式過去問は転載しない。** 本試験と同じ論点・同じ問われ方でオリジナルに書き起こす。
  このリポジトリは public なので、私的複製の例外（個人・家庭内）の範囲外になるため。
  公式の過去問はアプリの設定画面から日本FP協会の公開ページへリンクしている。
- **法令基準日を `lawBase` に明記する。** 2026年6月〜2027年5月実施分は「2026年4月1日現在施行の法令」。
  令和7年度改正（基礎控除58万円・給与所得控除の最低保障65万円・扶養親族等の所得要件58万円・
  特定親族特別控除の新設）は出題対象なので、改正後の数値で作成している。
- **改正が頻繁で数値が動く論点**（住宅ローン控除の借入限度額など）は、
  骨格だけを問題にして、細かい表はカードの注記で「試験直前に最新版で確認」と促す。
